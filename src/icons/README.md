# Contact icons

- `github.svg`: [Primer Octicons, mark-github-16](https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg), covered by `Octicons-LICENSE.txt`.
- `hugging-face.svg`: [official Hugging Face brand assets](https://huggingface.co/brand), downloaded from `https://huggingface.co/front/assets/huggingface_logo-noborder.svg`. The SVG uses its original colors with a responsive viewBox.
- Email and LinkedIn icons are defined directly in `src/shell/icons.ts`.

SVGs are embedded in the page and hidden from assistive technology because each icon has an adjacent text label.
