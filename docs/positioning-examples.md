## The 5 patterns that repeat most

1. **Role @ Company beats adjectives** — ~every title row is nouns only ("@vercel CEO", "Design Engineer"); no "passionate", no "ninja".
2. **Current thing + ex-proof** — "founder @dubdotco | previously @vercel", "Claude Code @anthropicai. prev YC W20"; the ex-employer is the credential.
3. **"I build/teach/make X for Y"** — the dominant sentence shape (TkDodo, Wes Bos, Delba, Cassidy, Arvid); verb + audience + outcome.
4. **Proof is a number or a name** — revenue/mrr (levelsio), stars/visitors (nutlope apps), acquisitions (mxstbr, nikitabier), shipped features (rogie, shadcn); never "experienced".
5. **One niche, stated plainly** — "DX and education systems", "tv for developers", "interaction designer", "Systems Engineer"; specific enough to be remembered, short enough to scan.
